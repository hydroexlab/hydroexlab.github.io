# HydroExLab — Research page editing guide

## Replace a card image
1. Prepare a landscape image (ideally 1500 × 900 pixels) and save it as WebP.
2. In GitHub, open `assets/research/` and upload the replacement using the **same filename** (or upload with a new filename and update the references).
3. Commit the change. Both the card and its detail page use the same image.

## Edit a research card
Open `research.html`, locate the research title, and edit its title or description inside the corresponding `<a class="research-card ...">` block.

## Edit a detail page
Open `research/<topic>.html` and edit the text in the `detail-overview` paragraph. Keep unpublished methods and proposals private.

## Add published work later
Add a short list of verified publications or public research figures to the appropriate detail page.

## Publishing
Upload these website files to the root of the public GitHub Pages repository `hydroexlab.github.io`, preserving folder structure. Check GitHub Pages settings and verify the site before changing domain DNS.

AI-generated thematic images are illustrative and do not represent actual laboratory facilities or results.


## Advanced Flood Modeling figures

The selected published figures are in `assets/figures/advanced-flood-modeling/`. Replace an image with a file of the same name to update it. The individual page is `research/advanced-flood-modeling.html`. Confirm publisher figure-reuse terms before public deployment.
