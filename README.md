# HydroExLab website — initial prototype

A free, static GitHub Pages website with eight working navigation pages.

## Preview
Open `index.html` in your browser.

## Publish
Upload the contents of this folder (not the folder itself) to the root of the public `hydroexlab/hydroexlab.github.io` repository. In repository Settings → Pages, choose Deploy from a branch, branch `main`, folder `/ (root)`, and save. The website will be available at `https://hydroexlab.github.io` after deployment.

## Edit
- Navigation and page content: each `.html` file
- Colors, spacing, fonts: `assets/style.css`
- Main image: `assets/river-landscape.svg` (illustration placeholder; replace with your own licensed photograph and update `index.html`)
- Mobile menu: `assets/site.js`

Do not change the DNS for hydroexlab.com until the new website is reviewed and ready.
